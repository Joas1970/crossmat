# CrossMat

Contas cruzadas com adição, subtração, multiplicação e divisão. O jogo roda no navegador, sem login e sem banco de dados. O progresso fica salvo no próprio aparelho.

## Como jogar

Toque um número da bandeja e depois uma casa vazia. Cada conta é dois números e uma operação, lida da esquerda para a direita ou de cima para baixo. Verde confirma. Vermelho pede ajuste.

## Desenvolvimento

```bash
npm install
npm run dev
```

O servidor local usa a porta 8080.

## Publicar

O projeto está preparado para a Vercel (`vercel.json`). Também é possível gerar a versão de produção com `npm run build`.
